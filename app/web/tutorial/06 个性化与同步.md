# 06 个性化与同步

最后一篇：把 RyuuMD 调成你喜欢的样子。

## 主题与配色

- 工具栏「深色 / 亮色」按钮（`Ctrl+Shift+L`）对切明暗；
- 设置 → 外观 →「配色方案」：RyuujiDesign 六套色板（霜纸靛蓝、和红、藤色、柳染、水浅葱、樱花），点选即时生效，每板自带明暗双态；
- 「正文字体」切换编辑器正文字体（默认霞鹜文楷），外壳始终为 MiSans；「等宽字体」管源码模式与代码块。

> 试试看：打开设置（工具栏最右齿轮）→ 外观，挨个点一遍色板。

## 阅读氛围（状态栏右侧图标）

| 开关 | 效果 |
| --- | --- |
| 可读宽度 | 正文限宽居中，长行不疲劳 |
| 专注模式 | 淡化非当前段落，收起侧栏 |

三者都会被记住，重启后保持。编辑区缩放用 `Ctrl+=` / `Ctrl+-` / `Ctrl+0`。

## 多窗口

- 工具栏「新窗口」、首页仓库卡片悬浮「新窗口打开」；
- 每个窗口独立编辑不同文档，共享同一套主题与偏好；
- 设为默认应用后双击 `.md` 自动开新窗口（设置 → 通用 →「默认 Markdown 应用」）。

## 可选云同步（自备 WebDAV）

官方不提供云端。需要跨设备时，用你自己的 WebDAV（坚果云 / Nextcloud / 群晖 / AList / Seafile）：设置 → 云同步 → 填好后勾选启用，再按仓库或全部同步。笔记始终留在本地，云端只是副本；不会自动删除任何一侧的文件，冲突时云端版本另存为 `*.conflict-时间.md`。

> [!note] 坚果云小贴士
> 密码栏要填网页端「账户信息 → 安全密码」里的应用密码，不是登录密码。
