# 04 双链与知识管理

这是 RyuuMD 最「Obsidian」的一面：用 `[[双链]]` 把笔记连成网络。

## 双向链接

在正文写 `[[笔记名]]`（键入 `[[` 会弹出仓库笔记列表，可过滤插入）：

- 本页的上一篇/下一篇导航就是双链，**单击即可跳转**；
- 支持别名与锚点：`[[01 快速上手|快速上手]]`、`[[example#表格]]`；
- 链接的笔记不存在时，点击会询问是否**创建**它。

> 试试看：在下面新建一行，输入 `[[`，选择「example」插入，然后单击它跳转，再回来。

## 侧栏「链接」页签

打开侧栏第四个页签「链接」：

- **反向链接**：哪些笔记链到了当前这篇（本站每篇都链向 [[欢迎使用 RyuuMD]]，打开它看看反链）；
- **本文链出**：当前文档里的全部双链与相对路径链接。

## 仓库级健康管理（命令面板 `Ctrl+Shift+P`）

| 命令 | 作用 |
| --- | --- |
| 仓库待办 | 汇总所有未勾选的 `- [ ]` |
| 浏览标签 | 汇总正文里的 `#标签` |
| 断开的双链 | 找出指向不存在笔记的链接 |
| 孤立笔记 | 找出没有任何链接进出的笔记 |
| 未链接提及 | 别的笔记提到了当前笔记名、却没做成双链的句子 |
| 仓库统计 | 篇数 / 待办 / 标签 / 断链摘要 |

> 试试看：现在按 `Ctrl+Shift+P` 执行「仓库待办」——本教程里散布的待办会被全部列出。

## 大纲与快速打开

- 侧栏「大纲」页签实时列出当前文档的标题结构，点击跳转；
- `Ctrl+P` 快速打开：输入笔记名直达；空查询时优先展示最近文件，输入不存在的名字可直接**新建**；
- `Ctrl+Shift+F` 全文搜索当前仓库；`Ctrl+F` 本文查找，`Ctrl+H` 替换，`Ctrl+G` 转到行。
