# 01 快速上手

五分钟认识 RyuuMD 的工作方式。

## 界面速览

```
┌───────── 工具栏：首页 / 侧栏 / 打开 / 新建 / 保存 / 搜索 / 新窗口 / 所在目录 ─────────┐
│  侧栏            │                                                              │
│  目录·大纲·最近·链接 │                     编 辑 区（即输即排）                       │
│                  │                                                              │
└───── 状态栏：路径 · 字数 · 缩放 · 视图开关 · 渲染/源码 ──────────────────────────────┘
```

- **侧栏右缘**可以拖拽调宽，双击手柄恢复默认；
- 点状态栏最左的**路径**，当前文件会在目录树中高亮定位。

## 打开与保存

- 新建：`Ctrl+N`，保存：`Ctrl+S`（第一次保存会让你选位置）；
- **自动保存**默认开启：已保存的文档停止输入约 2 秒后自动写盘；
- 把 `.md` 文件或文件夹**拖进窗口任意位置**即可打开。

> [!tip] 未命名的新文档不会被自动保存打扰——它只属于你按下 `Ctrl+S` 的那一刻。

## 两种编辑模式（右下角切换）

| 模式 | 适合 |
| --- | --- |
| **渲染**（默认） | Typora 式所见即所得：输入即排版，标记即消失 |
| **源码** | 纯 Markdown 文本，精细调整、查看原始语法 |

切换时**阅读位置保持不变**。超过 512KB 的大文档会自动以源码模式打开保持流畅。

> 试试看：点右下角「源码」看看本页的真实 Markdown，再切回「渲染」。

## 首页 = 工作台

按 `Ctrl+Shift+H`（或工具栏「首页」）回到首页：

- **仓库** = 你收藏的笔记目录，一键切换；卡片悬浮可置顶、重命名、新窗口打开；
- **最近打开**自动记录文件与文件夹，失效项点击后自动清理；
- 按 `Esc` 从首页回到编辑器。
