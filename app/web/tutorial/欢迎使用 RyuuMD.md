# 欢迎使用 RyuuMD 👋

这是 **RyuuMD 学习仓库** —— 一个内置的交互式教程。它是复制到你电脑上的独立副本，**随意涂改、删除都没关系**，随时可以这里练习每一项功能。

> [!note] 怎么使用这个仓库？
> 像读一本手册一样从上往下读，每篇末尾有「下一篇」链接（双链，点击即跳转）。
> 边读边动手：教程里的每个「试试看」都可以直接在本页操作。

## 三步热身

- [ ] 按 `Ctrl+Shift+L` 切换一次暗色主题（再按一次切回来）
- [ ] 把光标移到下一行，输入 `/` 呼出命令菜单，随便插入一个元素
- [ ] 点击右侧侧栏底部的「大纲」页签，看看本文的结构
