# 02 排版与斜杠命令

RyuuMD 的排版有**两条路**：直接敲 Markdown 标记（`#`、`-`、`>`），或者键入 `/` 从菜单里选。两条路效果完全相同，选顺手的即可。

## 基础排版

在空白行试试这些标记（渲染模式下输入即生效）：

| 输入 | 得到 |
| --- | --- |
| `# ` / `## ` … | 一到六级标题 |
| `- ` / `1. ` | 无序 / 有序列表 |
| `- [ ] ` | 可勾选的待办 |
| `> ` | 引用块 |
| ` ``` ` | 代码块 |
| `**粗**` `*斜*` `~~删~~` `==亮==` `` `码` `` | 行内格式 |

> 试试看：在本段下面新建一行，输入 `> ` 写一句引用。

## 斜杠命令 `/`

在编辑区键入 `/`，输入关键词过滤，`↑↓` 选择，`Tab` / `Enter` 插入：

- `/h1`～`/h6` 标题；`/table` 表格；`/code` 代码块；`/todo` 待办；
- `/date`、`/time` 插入此刻的日期时间；
- `/tip` 插入提示块（本文的彩色框就是它）。

**右键**编辑区会唤起同一个面板：顶部是剪贴板与「在资源管理器中打开所在目录」，下方是全部插入命令。

### 两种触发风格

设置 → 通用 →「操作风格」可切换：

| 风格 | 例子 |
| --- | --- |
| Typora + Notion（默认） | `/h1`、`/table`、`/todo` |
| Typora + Wolai | `/bt1`、`/bg`、`/lb`（拼音缩写） |

中文名两种风格通吃：直接输入 `/标题`、`/表格` 也能搜到。

## 段落转换与块操作（右键）

- **段落转换**：光标停在段落上（或框选多段）→ 右键 →「转换为」→ 正文 / 标题 / 列表 / 引用 / 代码块（渲染 / 源码模式都可用）；
- **表格中**（仅渲染模式）：插入/删除行列、删除表格；
- **代码块 / 公式块中**（仅渲染模式）：复制源码、转为普通文本、删除块。
