# RyuuMD 全功能特性分项测试计划

对应实现版本：仓库管理 + 软件首页 + 多窗口 + 单实例 + 默认应用之后。
自动化分层：**Python API 层单元测试**(`tests/test_api.py`,unittest,零依赖）与
**真实窗口端到端测试**(`tests/test_e2e.py`,pywebview + evaluate_js 探针断言）。
统一入口：根目录 `run_tests.py`（先单测后 E2E，任一失败退出码非零）。

> E2E 全程使用**临时 APPDATA**（隔离用户真实配置）与临时目录文件，
> 并 hook `window.confirm` 恒为 true（防未保存确认框阻塞自动化）。

## 当前实测结果

- **单元测试：45/45 通过**(文件读写、文件夹树、open_path、会话恢复、配置容错、
  资源存在性、**仓库管理、fsutil 计数、文件关联、多窗口 API、单实例转发**）。
- **E2E:31/31 通过**（含 **T00 首启进首页、T24-T29 首页仓库全流程**）。
- 多窗口/单实例已做真实进程冒烟：主实例启动写锁 → 第二进程 254ms 秒退
  （转发成功）→ 主实例新窗口打开目标文档（last_file 证实）。

### 本轮修复记录（待查项已清零）

- **T10 待办勾选失效（真实产品 bug)**:`editor.js` 的 checkbox 守卫（捕获阶段 stopPropagation + 手动翻转 DOM checked）只改了 DOM、没更新 Vditor 内部 model，下一帧 Vditor 从 model 重渲染把勾选刷回——**勾选完全失效**。**已移除该守卫**，改由 Vditor 原生处理（正确同步源码 `[ ]`↔`[x]`)。
- **T19 字数/脏标记**:updateCount 依赖 Vditor 内部 input 回调，**合成 InputEvent 无法驱动**（真实键入才可），属测试方法限制而非产品 bug;updateCount 本身经 loadDoc 路径验证正确（去空白计数，`#`/句号等非空白字符计入）。测试改走 loadDoc 可达路径。

### E2E 运行须知

1. 须真实窗口运行（Vditor 渲染依赖 rAF/窗口焦点）;
2. **运行前关闭其他 RyuuMD / WebView2 实例**——残留 `msedgewebview2.exe` 进程会导致首个用例即失败；
3. 大文档夹具用「真实笔记形态」（多行短行）；不用「单段 56 万字重复」病态输入（对 Vditor sv 全量高亮是硬性能边界，会卡死 WebView2 主线程，属已知边界，见 J 节手动项）。

### 排查过程中沉淀的关键经验（测试环境，非产品 bug)

- **evaluate_js 注入中文字符串字面量不可靠**：手工 `\uXXXX` 转义拼进 JS **单引号**字符串时反斜杠被字面保留（中文变乱码，长度翻 6 倍）;**必须用 `json.dumps`(JV)生成双引号字符串**才保真。本套测试的所有中文注入/断言统一走 `JV()`。
- 残留 `msedgewebview2.exe` 会让新窗口行为异常（首个用例即败），跑前先清理。
- 连续无间隔的 `evaluate_js` 注入（setValue→setMode 连发）会撞上 Vditor 内部异步任务未 settle 的竞态；真实用户操作间隔天然存在，测试用例间已留 0.5s 间隔。

## 手动验证清单（每次发布前过一遍）

1. 右键「打开方式」/ 拖到 exe 图标启动打开 md(A4)
2. 原生打开/保存/文件夹对话框与取消分支（B9)；首启空态「打开文件夹」只弹一次（D4)
3. 键入 `/h1`、`/bt1`(wolai 风格）过滤与插入（G3/G4)
4. 拖入文件 / 文件夹（I1/I2)，拖放提示显隐（I3)
5. 视觉走查：宽表格、长代码块、长公式、暗色主题、欢迎窗口、**首页两种视图亮暗主题**（H1-H5、F、K)
6. 30 万字文档连续输入流畅度（J3)；dirty 状态切文件弹确认（E7)
7. **多窗口**：首页卡片「新窗口打开」两个仓库并排编辑；关窗口尺寸记忆（L9)
8. **单实例**：应用运行中双击另一个 md → 已有实例新窗口秒开（L5)
9. **默认应用**：设置 → 设为默认 → 系统对话框勾「始终」→ 验证文档出现、
   设置按钮显示「已是默认 ✓」（L8)；程序移动位置后重设一次仍有效
10. **启动页**：设置切「首页」→ 重启进首页；切回「上次会话」→ 重启恢复（K2)
