# RyuuMD 使用手册

面向日常使用者的完整指南。RyuuMD 是一款轻量、全本地、极速的 Markdown
编辑与阅读工具：以仓库形式管理笔记目录，首页一键切换，支持多窗口。

---

## 1. 安装与启动

### 1.1 直接运行（绿色版）

**Windows**

- **onedir 版**：解压后双击 `RyuuMD/RyuuMD.exe`；
- **onefile 版**：双击单个 `RyuuMD.exe`（首次启动略慢，需解压到临时目录）。

**macOS（Apple Silicon，未公证）**

在 Mac 上解压 `RyuuMD-mac-arm64.tar.gz`（推荐）或 `.zip` 后：

1. 右键 `RyuuMD.app` →「打开」→ 提示里再点「打开」（未公证包会被拦截，这是正常的）；
2. 或双击同目录的「打开 RyuuMD.command」；
3. 或终端执行 `xattr -cr RyuuMD.app` 后再双击。

仅支持 M 系列 Mac。配置在 `~/Library/Application Support/RyuuMD`。
「设为默认 Markdown 应用」仅 Windows 提供；Mac 请用右键 →「打开方式」。

无需安装、无需联网，所有资源内置本地。

### 1.2 源码运行（开发者）

```bash
pip install -r requirements.txt
python main.py        # 或双击 run.bat
```

### 1.3 三种打开方式

1. 直接启动应用 → 进入首页或恢复上次会话；
2. 把 `.md` 文件或文件夹**拖到 exe 图标**上启动；
3. 右键 md 文件 → 「打开方式」→ RyuuMD（设为默认后双击即可）。

> RyuuMD 是**单实例**应用：已在运行时再打开 md 文件，会在已有实例中
> **秒开一个新窗口**，不会重复冷启动。

## 2. 首页：你的笔记工作台

启动后首先看到首页（默认；若改为「恢复上次会话」，则会回到退出前的文件夹与文档，
点工具栏「首页」随时回来）。

### 2.1 快速操作

| 卡片 | 作用 |
| --- | --- |
| 新建文档 | 进入编辑器开始写作，`Ctrl+S` 保存时选择位置 |
| 打开文件 | 浏览打开单个 Markdown 文件 |

仓库相关入口在「我的仓库」标题右侧的 `+`：添加已有目录、新建仓库、新建文件夹、打开学习仓库。

> 首次启动后「学习仓库」会自动出现在仓库列表置顶位置——它是复制到
> `%APPDATA%/RyuuMD/学习仓库` 的独立副本，随意涂改不影响内置原件；
> 移除后想再看：仓库列表 `+` 或 设置 → 通用 →「学习仓库」→ 打开。

### 2.2 仓库列表

仓库 = 你的笔记目录（参考 Obsidian 的 vault 概念）。添加后长期驻留首页，
点击即切换。

- **两种视图**：右上角切换**卡片视图**（大图块，信息全）/ **列表视图**（紧凑单行），
  偏好自动记忆；
- **卡片信息**：仓库名、路径、md 文档数（大仓库显示 `N+`）、最后打开时间；
- **悬浮操作**（鼠标移到卡片上出现）：
  - 置顶 / 取消置顶 —— 置顶仓库永远排最前；
  - 云同步 —— 在已启用并配置 WebDAV 后，为该仓库打开/关闭同步；
  - **新窗口打开** —— 多仓库并排写作；
  - 重命名 —— 只改显示名，不动目录；
  - 在资源管理器中显示；
  - 移除 —— 仅从列表移除，**不会删除磁盘上的任何文件**。
- 目录被移动/删除的仓库会**灰显**并标注「目录不存在」，可选择移除或恢复目录。

### 2.3 最近打开

自动记录最近打开的文件与文件夹（最新在前），并分两组展示：

- **最近文件**：最新 3 个文件单独成卡（大点击区，一触即达）；
- **其他**：更早的文件与浏览过的文件夹，紧凑行式排列；
- 点击直接打开；失效项（已移动/删除）点击后自动清理；
- 文件夹项悬浮出现「**存为仓库**」按钮 —— 临时浏览觉得好用，一键收藏；
- 「清空」按钮清空全部记录；没有记录时不显示。

### 2.4 随手记

首页底部 **随手记** 写在本机用户数据目录的 `scratch.md`，与仓库无关。有无最近打开时，首页模块顺序不变。

### 2.5 进出首页

- 工具栏最左「首页」按钮，或 `Ctrl+Shift+H` 切换；
- `Esc` 关闭首页回到编辑器；
- 打开任何文档/仓库后自动回到编辑器。

## 3. 编辑与阅读

### 3.1 界面布局

```
┌──────── 工具栏（首页/侧栏/搜索/AI/主题/设置）─┐
│ 侧栏（目录/大纲/最近/链接） │            编辑器（Vditor）            │ AI 侧栏 │
│ 右缘可拖拽调宽            │                                     │（提问/概括/知识谱系）│
└──────── 状态栏（路径 | 已保存/未保存 | 字数 | 云同步 | 可读宽度 | 渲染/源码）─────┘
```

工具栏只留首页、侧栏、搜索、AI、文件名、主题、设置。「保存至源 / 合并源」仅工作副本模式出现。打开文件夹/打开文件/新建/保存/新窗口/所在目录走命令面板或快捷键。保存状态在状态栏，点一下即保存。首页不显示当前文件名。

### 3.2 两种显示模式（右下角切换）

- **渲染模式**（默认）：Typora 式即时渲染，所见即所得；
- **源码模式**：纯 Markdown 文本，适合精细调整；
- 切换时**阅读位置保持不变**（按滚动比例还原，长文档不跳）；
- 超过 512KB 的大文档自动以源码模式打开（保持流畅），可手动切回。

### 3.3 斜杠命令与右键菜单

在编辑区键入 `/` 唤起命令菜单过滤插入；**右键**唤起同一面板——
顶部是**剪贴板组**（复制 / 剪切 / 粘贴，无选区时复制剪切置灰），
下方是全部插入命令。支持两种触发风格（设置中切换）：

| 风格 | 示例 |
| --- | --- |
| Typora + Notion（默认） | `/h1`、`/table`、`/code`、`/todo` |
| Typora + Wolai | `/bt1`（标题1）、`/dmk`（代码块）、`/lb`（列表） |

上下箭头选择，`Tab` / `Enter` 插入，`Esc` 关闭。

**段落转换（对标 Typora 段落菜单）**：把光标停在段落上、或框选若干段落，右键 →「转换为」，
可切换为 正文 / 1~6 级标题 / 无序·有序·待办列表 / 引用 / 代码块；框选多段时逐段转换，
加粗、链接等行内格式会保留。

**块级操作（右键随光标位置变化）**：仅渲染模式可用；源码模式下这些菜单不出现（段落转换仍可用）。

- 光标在**表格**中：向上/向下插入行、向左/右侧插入列、删除行、删除列、删除表格；
- 光标在**代码块**中：复制代码、转换为普通文本、删除代码块；
- 光标在**公式块**中：复制公式源码、转换为普通文本、删除公式块。

**图表与公式**：

- 「图表」组命令一键插入 mermaid 模板：流程图 `/lct`、时序图 `/sxt`、甘特图 `/gtt`、
  类图、状态图、饼图、ER 图、用户旅程图、思维导图 `/swdt`、时间线 `/sjx`；
  渲染模式即时成图，切换明暗主题时图会自动按新主题重渲染。
- 行内公式 `$…$`（`/xngs`）与公式块 `$$…$$`（`/gsk`）即时渲染；
  公式引擎可在 设置 → 通用 切换：KaTeX（默认，快）/ MathJax（Typora 同款，兼容更多 LaTeX 宏）。

### 3.4 侧栏页签

- **目录**：当前仓库/文件夹的 md 文件树，点击打开，目录可折叠；
  命令面板可「折叠全部目录 / 展开全部目录」。
  **右键文件**：重命名、移动到…、在资源管理器中显示、删除（回收站）；
  **右键文件夹**：新建笔记、新建文件夹、在资源管理器中显示。
  空仓库会显示「新建笔记」按钮。
  侧栏右缘可**拖拽调整宽度**（180–480px），双击手柄恢复默认 256px，宽度会记住。
- **大纲**：当前文档标题结构，实时更新，点击跳转；
- **最近**：最近打开列表（与首页最近区同源）；
- **链接**：当前笔记的**反向链接**（谁链到了我）与文内 `[[双链]]` 链出。

> 小技巧：重命名/移动当前正在编辑的文件时，编辑器会自动跟随新路径；
> 删除正在编辑的文件时，内容会保留为「未保存草稿」，编辑成果不丢。

### 3.5 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 保存 | `Ctrl+S` |
| 打开文件 | `Ctrl+O` |
| 新建文档 | `Ctrl+N` |
| 快速打开笔记 | `Ctrl+P`（空查询优先最近文件；输入新名可选新建） |
| 命令面板 | `Ctrl+Shift+P` |
| 仓库搜索 | `Ctrl+Shift+F`（工具栏「搜索」；标题 / 内容即时搜，语义与 `ask ` 按 Enter） |
| 本文查找 | `Ctrl+F` |
| 查找替换 | `Ctrl+H` |
| 转到行 | `Ctrl+G` |
| 今日日记 | `Ctrl+Shift+D` |
| 放大 / 缩小 / 重置 | `Ctrl+=` / `Ctrl+-` / `Ctrl+0` |
| 切换侧栏 | `Ctrl+Shift+B` |
| 切换亮/暗主题 | `Ctrl+Shift+L`（与工具栏「主题」相同，会记住） |
| 首页 | `Ctrl+Shift+H`（`Esc` 关闭） |
| 关闭弹窗 / 首页 | `Esc`（设置、欢迎、确认框、首页依次关闭） |
| 命令菜单 | `/` |

### 3.6 粘贴与拖入图片

已保存的文档：图片落到同目录 `{文件名}.assets/`（与 Typora 一致），正文插入相对路径，渲染模式会自动按文档目录显示。
尚未保存但已打开仓库时，落到仓库下的 `assets/`。请先保存或打开仓库再贴图。

把 `.png` / `.jpg` 等图片拖进编辑区同样插入；拖入 `.md` 或文件夹仍是打开文档/仓库。

### 3.7 双向链接

在正文写 `[[笔记名]]`（可加 `|别名` 或 `#标题`）。渲染模式下链接会高亮，**单击**或 **Ctrl+单击** 打开对应笔记；找不到时会询问是否创建。
键入 `[[` 会弹出当前仓库笔记列表，可过滤后插入。也支持点击文内的相对路径 md 链接。外链（http/https）用系统浏览器打开，不会把应用整页导航走。

### 3.8 每日笔记、自动保存、导出

- **今日日记**：`Ctrl+Shift+D` 或命令面板「今日日记」。默认写在当前仓库的 `日记/YYYY-MM-DD.md`（设置里可改子目录名），当天第一次打开会自动建文件。若仓库里有 `模板/日记.md`，新建时用该模板（占位符 `{{date}}` `{{title}}` `{{week}}` 等）。
- **笔记模板**：在仓库下建 `模板/` 文件夹（命令面板「打开模板文件夹」），放入 `.md`。之后命令面板会出现「插入模板：…」和「从模板新建：…」。占位符：`{{title}}` `{{date}}` `{{time}}` `{{week}}` `{{year}}` `{{month}}` `{{day}}`。
- **自动保存**：默认开启。仅对**已经保存过路径**的文档在停止输入约 2 秒后写盘；未命名新文档不会突然弹出另存框。
- **可读宽度**：状态栏图标或命令面板「切换可读宽度」。正文限制最大行宽并居中，对标 Typora（不占设置项，重启后记住开关）。
- **转到行**：`Ctrl+G` 或命令面板「转到行」，按行号滚动到对应位置。
- **快速收集**：命令面板「快速收集」，把一段文字追加到当前仓库根的 `收集箱.md`（按时间分节）。
- **目录全折叠**：命令面板「折叠全部目录 / 展开全部目录」。
- **当前文件**：命令面板可「重命名当前文件」「移动当前文件」「在新窗口打开」。
- **导出 HTML**：命令面板「导出 HTML」，另存为可独立打开的网页。
- **插入日期/时间**：斜杠菜单或命令面板的 `/date`、`/time`。
- **复制**：命令面板可复制当前路径、双链 `[[笔记名]]`、HTML 或 Markdown；「复制当前笔记」在同目录生成 `名 副本.md`。
- **在目录中定位**：命令面板「在目录中定位当前文件」，或点击状态栏左侧路径。
- **仓库待办 / 标签 / 断链**：命令面板「仓库待办」列出未勾选的 `- [ ]`；「浏览标签」汇总 `#标签`；「断开的双链」「孤立笔记」做健康检查；「未链接提及」找出其它笔记里写了当前笔记名但未做成 `[[双链]]` 的句子；「仓库统计」弹出篇数摘要。
- **AI 概括与提问**：工具栏「AI」打开 AI 侧栏，可概括当前文档/仓库、生成知识谱系、自由提问（详见第 6 章）。
- **外部修改**：已保存且本地无未保存更改时，若磁盘文件被别的程序改过，会自动重新载入并提示。

### 3.9 拖拽打开

把 `.md` 文件或文件夹直接拖进窗口任意位置即可打开（文件夹作为工作区加载到侧栏）。

## 4. 设为默认 Markdown 应用

1. 打开 **设置 →「默认 Markdown 应用」→ 点「设为默认」**；
2. 系统弹出「打开方式」对话框，选择 **RyuuMD** 并勾选**「始终」**；
3. 确认后会自动打开一篇「设置成功」文档 —— 看到它说明已生效。

之后双击任何 `.md` / `.markdown` / `.mdx` 等文件都会用 RyuuMD 打开；
已在运行时秒开新窗口。设置页按钮会显示「已是默认 ✓」。

> 为什么要弹系统对话框？Windows 10/11 出于安全禁止程序静默修改默认应用，
> 由用户在系统对话框中确认一次是微软认可的唯一方式（VSCode、Typora 同款流程）。
> 本操作只写当前用户注册表（HKCU），无需管理员权限。

## 5. 可选云同步（自备 WebDAV）

RyuuMD **官方不提供云端**，笔记默认只在本地。若需要跨设备，请使用自己的 WebDAV
（坚果云、Nextcloud、群晖、AList、Seafile 等），在设置里填好并**勾选启用**后才生效。

### 5.1 打开步骤

1. 设置 →「云同步」→ 打开「启用云同步」开关；
2. 填写服务器地址、用户名、密码（坚果云请用「应用密码」）、远端目录（默认 `RyuuMD`）；
3. 点「测试连接」确认通畅；
4. 再选同步范围：
   - 勾选「同步全部仓库」；或
   - 回到首页，在仓库卡片悬浮栏点云朵图标，逐个开启；
5. 可选：「保存后自动上传当前文件」「启动时自动同步」；
6. 点「立即同步」，或点状态栏「云同步」。

未勾选启用、未填地址、仓库未开启时，不会访问网络。

### 5.2 同步规则

- 本地与云端双向更新 Markdown 及常见配图（png/jpg/gif/webp/svg 等）；
- **不会自动删除**另一侧的文件，避免误删笔记；
- 两边都改过同一文件时：本地保留，云端版本另存为 `文件名.conflict-时间.md`；
- 单个文件超过 20MB 会跳过。

### 5.3 坚果云示例

- 地址：`https://dav.jianguoyun.com/dav/`
- 用户名：登录邮箱
- 密码：坚果云网页 → 账户信息 → 安全密码（应用专用密码）

## 6. AI 助手（Anthropic Messages）

RyuuMD 按 Anthropic Messages 协议连接你自己的接口（官方或兼容中转）。笔记仍在本地，请求发往你填写的 Base URL。

### 6.1 配置

设置 → **AI**：

| 项 | 说明 |
| --- | --- |
| Base URL | 例如 `https://api.anthropic.com`，也可填本地中转；仅 http/https，不跟随重定向 |
| API Key | 写入 `x-api-key` |
| 模型 | 写入请求 JSON 的 `model` |

三项配齐后，概括、语义搜索、`ask` 问答与知识谱系才会发出 `POST …/v1/messages`。缺任一项时对应功能返回明确错误。设置页提供「测通」核对接线是否填全。即时通讯 webhook 收在「高级」。

### 6.2 AI 侧栏

工具栏「AI」按钮开关右侧 **AI 侧栏**，是 AI 交互的统一面板：

- 未配置时只显示「去配置 AI」，概括等按钮不出现。
- **提问**：底部输入框直接问，AI 结合当前仓库摘录回答；提问与回答成对留在日志里。
- **概括当前文档 / 概括当前仓库**：一键生成摘要，结果追加到日志。
- **知识谱系**：把仓库笔记目录交给模型，按主题分层梳理出知识大纲。生成结果在本窗口内缓存，按钮随即变为「刷新知识谱系」，点击重新生成；切换仓库后回到「生成」态。
- **Esc** 关闭侧栏；进行中的请求未完成时按钮会锁住，避免连点重复计费。
- 每条结果可 **复制** 或 **插入当前文档**。大纲按安全的 Markdown 子集渲染。

命令面板也有对应的「概括当前文档 / 概括当前仓库 / 生成 / 刷新知识谱系」命令，会先展开侧栏再执行；已生成过谱系时该命令会刷新。

### 6.3 仓库搜索

`Ctrl+Shift+F` 或工具栏「搜索」打开搜索面，可切换：

- **标题**：匹配文件名或相对路径
- **内容**：匹配笔记正文
- **语义**：把查询交给已配置的模型，按语义挑选相关笔记；**按 Enter 才请求**，输入过程不消耗额度

查询以 `ask` 加空格开头（例如 `ask 什么是 WebDAV`，大小写不敏感）时，**按 Enter** 关闭搜索面板并在 AI 侧栏提问。停顿不会自动请求。`asking` 或单独的 `ask` 仍按普通搜索处理。

知识谱系在本窗口按仓库缓存；保存、新建、复制、收集、日记、重命名、移动或删除笔记后缓存失效。命令面板「生成 / 刷新知识谱系」在已生成过时会重新请求。仓库过大时只根据前若干篇摘录，结果会注明可能不完整。

### 6.4 让外部 AI 客户端接管（MCP / 命令行）

RyuuMD 内置 MCP 服务与命令行入口，可把笔记能力接给 Claude Code 等 AI 客户端：
读写笔记、管理仓库、搜索索引、每日日记、收集箱、云同步、IM 发送等全部可自动化。

```bash
RyuuMD mcp --install    # 注册到 Claude Code（重开会话后生效）
```

命令行用法与完整能力清单见 `README.md`「命令行与 MCP」；给 AI 代理的接入文档见仓库根目录 `AI_GUIDE.md`。

## 7. 多窗口

- 命令面板 **打开新窗口**：一键开出一个新窗口（显示首页）；
- 首页仓库卡片 → 悬浮操作 → **新窗口打开**；
- 设为默认应用后，双击 md 文件自动在新窗口打开；
- 每个窗口独立编辑不同文档，共享同一套主题/偏好设置；
- 最后关闭的窗口的尺寸会被记住，作为下次启动的窗口大小。

> 已有窗口在运行时**再次启动程序**（双击图标）默认新开窗口；也可在
> 「设置 → 通用 → 再次启动程序」改为**激活当前窗口**。双击 md 文件不受
> 此项影响，始终开新窗口。

## 9. 常见问题（FAQ）

**Q：仓库和最近打开有什么区别？**
仓库是你显式收藏的笔记目录，长期驻留、可置顶重命名；最近打开是自动记录的
访问历史，会滚动淘汰。最近里的文件夹可以一键「存为仓库」。

**Q：移除仓库会删除我的笔记吗？**
不会。移除只是从 RyuuMD 的列表里去掉这条记录，磁盘文件毫发无损。

**Q：为什么大文档打开是源码模式？**
超过 512KB 的文档全量即时渲染会卡顿，自动以源码模式打开保证流畅；
右下角可随时切回渲染模式。

**Q：文件树里为什么看不到某些文件夹？**
隐藏目录（`.` 开头）、依赖/构建目录（`node_modules`、`dist` 等）以及 Typora 式
`*.assets` 配图目录会被自动过滤；超深/超大目录会截断显示并提示。

**Q：双击 md 打开的是旧版其他软件？**
重新执行第 4 节流程，在系统对话框中重新选择 RyuuMD 并勾选「始终」。

**Q：想把配置彻底重置？**
关闭应用后删除 `%APPDATA%\RyuuMD\config.json`（仓库列表、最近记录、偏好会清空，
不影响任何笔记文件）。

**Q：支持官方云盘或账号登录吗？**
不支持。官方不运营云端，避免绑定与隐私风险。把你已有的 WebDAV 填进设置即可，
也可以把仓库目录放到 OneDrive / 坚果云同步盘里，由那些客户端负责同步。
